# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.1.x   | :white_check_mark: |
| 1.0.x   | :x:                |

## Reporting a Vulnerability

Security is a top priority for **SM-quick-open**. Since this extension interacts with cloud lab instances, IP addresses, and SSH keys, we maintain strict client-side data isolation.

- **Zero Cloud Leakage**: No private keys, IP addresses, or credentials are ever sent to third-party servers. All operations occur strictly within your browser DOM.
- **Reporting**: If you discover any security issues or potential vulnerabilities, please report them directly via email to `support@softmania.in` or open a private security advisory on GitHub.
- We will acknowledge receipt of your report within 24 hours and issue a patch promptly.
